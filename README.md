## Blog

Posts live in `content/posts/*.md`; the file name is the URL slug (`content/posts/hello-world.md` → `/blog/hello-world`).

```md
---
title: My post
subtitle: One-line summary shown under the title and in previews
date: 2026-10-20
tags: [swift, macos]
cover: /blog/my-cover.jpg   # optional, file in public/blog/
coverAlt: Caption for the cover
draft: true                 # optional, only shown in `npm run dev`
---

Post body in Markdown (GFM: tables, task lists, fenced code with syntax highlighting).
```

See `content/posts/markdown-reference.md` for every supported element. The RSS feed is at `/blog/feed.xml`.

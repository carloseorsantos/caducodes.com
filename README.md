# caducodes.com — Developer Portfolio

Modern, Apple/macOS-inspired developer portfolio in English for **Carlos Santos** ([@caducodes](https://caducodes.com)).

Spotlights native macOS utilities built with **Swift 6 & SwiftUI** (**OpenCleaner for Mac**, **Win+V for Mac**, **Hit Mac Hard & Soft**, **Heeey!**), alongside full-stack engineering expertise (**CI&T**, **Next.js 15**, **TypeScript**, **Java / Spring Boot**).

---

## ✨ Features

- 🍏 **Flagship Spotlight**: Deep dive into pinned macOS apps (**OpenCleaner for Mac** and **Win+V for Mac**) with interactive macOS window mockups, Squarified Treemap heatmap visualizations, memory page gauges, and live clipboard search simulations.
- 🚀 **1-Click Downloads & Terminal Snippets**: Direct `.dmg` release download links and copyable `git clone` & `./Scripts/install.sh` commands.
- 📦 **Bento Grid Projects**: Showcases secondary creations (*Hit Mac Hard & Soft*, *Heeey! Live Marquee*, *Quanto Rendeu?*).
- 🔍 **Interactive Deep-Dive Modals**: Click any project to open a technical specification dialog with architecture breakdowns, feature matrices, and repository links.
- 💼 **Career Timeline**: 4+ years of professional engineering experience at **CI&T**.
- 🛠️ **Categorized Tech Stack Matrix**: Native macOS (Swift 6, Mach Kernel, AppKit), Frontend (React 19, Next.js 15, Tailwind CSS), Backend & Systems (Java, Spring Boot, WebSockets), and Tooling/DevOps.
- 📬 **Interactive Contact**: 1-click email copy, GitHub & LinkedIn direct integration.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with frosted glassmorphism & dark aesthetic
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Deployment**: [Vercel](https://vercel.com/) / Static Hosting

---

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
